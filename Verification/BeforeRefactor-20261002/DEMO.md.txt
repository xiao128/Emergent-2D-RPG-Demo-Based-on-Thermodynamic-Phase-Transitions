# 世界钟相变试炼 Demo

Unity 2022.3.62f1c1。打开 Assets/Scenes/PhaseArenaDemo.unity，点击 Play，再点击“开始试炼”。

## 本次玩法

开局 F 法杖钝击固定造成 12 点伤害，足以打倒普通怪物，同时施加 22.5 的推动冲量。冰火投射物基础质量为 1，敌方发射冲量为 6，玩家初始冲量为 0，生命为 160；它们与石头共用碰撞伤害和摩擦，可被 F 再次击飞，也能在空中互撞。首撞释放一次冰火温度脉冲，之后作为物理实体继续运动，双方无定时寿命，共享 250 个场地上限，超限移除最早生成的投射物。守卫附近共 4 块 MicroRock 的基础质量为 1，尺寸为普通石头的 0.55 倍；温度和磨损法则仍会改变实际质量。随着周目推进，双方生命增加，敌方增长更快，玩家需要利用碰撞、融冰落水与法则连锁来放大伤害；普攻伤害不会随周目增长。

出生点固定在地图左侧（−28，0），世界钟固定在右侧（28，0），保留墙边与 HUD 的安全边距。小地图以闪动绿色标出玩家、蓝色标出出生点、金色标出世界钟。普通周目有 19 只游荡怪物与两名守卫，共 21 只，正好为上一版 30 只的 70%；第八周目为 19 只游荡怪物和魔王。

河流改为常驻的一条横贯河流，中心高度为 y=10、宽四格，水体不随种子变化。南岸保留左右干地路线，北岸可以通过冻结河流探索。树木生成缩放为 1.65–2.10，约比上一版大八成，碰撞体同步增大；巨型石头仍固定且不可破坏，树木仍固定但可破坏，小石头可以推动。

前七周目，击败右侧两名守卫，实际拾取各自掉落的一枚碎片，到世界钟按 E。每次从尚未选择的十三种法则中随机提供三条。选择后显示“世界法则改变了”，累计法则保留，玩家恢复当周满血、常温与原始质量，回到左侧出生点。石头、树木、粗糙地面和怪物位置重新生成；河流位置保留、相态重置，世界钟与出生点固定。

第八周目，魔王出现在右侧世界钟。击败魔王即胜利。死亡重开整局，清空全部法则、碎片和周目进度。目标首次体验时长为 15–25 分钟，仍需要手动试玩确认。

## 生命成长

开局轻、中、重怪物为 18 / 28 / 42 生命，守卫为 60；玩家为 100。之后玩家每周目乘 1.25，敌方每周目乘 1.55，取整。物理质量、普攻伤害和基础推动力不随周目升级；“更大的力”由法则改变。

| 周目 | 玩家生命 | 轻怪生命 | 守卫生命 / 最终魔王 |
| --- | --- | --- | --- |
| 1 | 100 | 18 | 守卫 60 |
| 4 | 195 | 67 | 守卫 223 |
| 7 | 381 | 250 | 守卫 832 |
| 8 | 477 | 387 | 魔王 2579 |

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 施力移动；冷重物体移动更笨重，冰面难急转 |
| Shift + 移动 | 慢行，便于在磨损法则下控制速度；惯性仍由物理决定 |
| 鼠标左键 | 火焰调温 |
| 鼠标右键 | 冰霜调温 |
| F | 朝鼠标方向用法杖推动最近物体 |
| 空格 | 四面护盾，固定上下左右随玩家移动，持续四秒 |
| E | 靠近世界钟、带齐两枚碎片后选择法则 |
| Esc | 暂停或继续 |
| R | 失败或胜利后重开整局 |

冰火共用施法节奏。法杖钝击命中前方最近一个物体，包含固定直接伤害与推动冲量。护盾先以物理冲量推开附近怪物，随后形成固定四面屏障；受墙体阻挡而尚未退出的怪物可以向外离开。自己的弹丸可以出盾，推出的石头离开后恢复护盾碰撞，反弹回来时会被拦截。贴墙受遮挡的一面暂时隐藏，离开墙后恢复。

怪物不会一直贴身施力：先接近、停下蓄力，身体压缩并显示撞击方向，再冲撞和休整。普通怪物蓄力 0.85 秒，魔王 1.1 秒；方向在蓄力开始时锁定，玩家可以侧移避开。碰撞伤害仍使用原来的统一计算。

## 开局始终生效的规则

- 所有动力学实体使用统一的温度、质量、速度体系；发射和法杖推动采用固定冲量。
- 撞击伤害随有效质量和法向相对速度增长，静止接触不扣血，墙体不以无限质量制造伤害。统一速度阈值保留为 1.8。
- 物体向室温恢复；速度越快，风冷越强。温度硬上限为 −600～800°C；速度上限为石头 240、角色 60、弹丸 160。Unity 最大平移速度同步设为 240，动态实体使用连续碰撞检测。
- 水阻挡步行，法术可以穿过；水降到 0°C 以下结冰，冰面能通行、滑行；加热到 60°C 融化。
- 冰面融化后普通怪物落水死亡，玩家、精英、魔王扣血并返回可达的干地。
- 超过 100°C 形成蒸汽，弹丸进入一片连续蒸汽时速度减半。
- 小石头可推动，质量随生成体积改变；大石头固定、不可破坏；树木可破坏、过热自燃并给周围传热。

开局没有任何变量法则，包括“冷热改变重量”。未解锁时，加热石头不会使它变轻。

## 法则实验

法则卡使用短效果说明与操作例子；右侧悬停检查可以查看物体的质量、温度、速度，热胀冷缩生效时还显示占地倍率。世界内的飘字、石头运动轨迹与屏幕提示展示因果。

磨损对玩家同样生效，左侧会显示物质剩余比例。温暖且高速时应减速或冷却；给石头调温时可以稍站远些，避免反复把自己也加热。

| 已解锁法则 | 可尝试的操作 |
| --- | --- |
| 冷热改变重量 | 越冷越重，越热越轻，改变质量不改变当前速度；加热后更容易推动，先击飞再冷却可保留速度并提高质量 |
| 冷物体会反弹 | 冷却石头、敌人或墙，利用反弹路线命中 |
| 冷物体更滑 | 极寒物体的地面阻力仅剩 10%，石头滑得更远 |
| 热物碰水会弹开 | 加热水边石头，在真正的接触边缘触发汽化反冲 |
| 冷热相撞会放电 | 让很热与很冷的物体相撞；参与物体越重，反应越强 |
| 撞击会升温 | 强烈撞击把部分动能转成热量，再触发质量变化、融冰或反冲 |
| 滑行会磨损 | 粗糙地面滑行生热；温暖高速物体每米损失 5% 质量 |
| 轻小高速物体会爆炸 | 小碎石离手后或撞击时爆炸；也可组合磨损、变轻和加速 |
| 冷重物体会吸引轻物 | 冷却大石头，用引力牵引附近热而轻的物体 |
| 莱顿弗罗斯特：热胀斥力 | 实体表面接近至 0.6 内且温差超过 80°C，产生等大反向斥力；热石头可推开冷怪物，固定障碍物保持不动 |
| 极寒脆性 | 将低于 −50°C 的单位在一秒内加热到 100°C 以上，引发按温差与参与质量计算的热冲击伤害；缓慢升温不会触发 |
| 更大的力 | 所有实体施加的推力与冲量变为两倍，包括移动、法杖、魔法发射、护盾排斥、怪物冲撞、汽化、引力、爆炸与热胀斥力 |
| 热胀冷缩 | 每 0.2 秒检查占地，热物最多增大至 1.8 倍、冷物缩至 0.6 倍；先做重叠检测，空间不足不膨胀；夹在膨胀物体和固定环境之间的生物持续受挤压伤害 |

各条法则都能独立获得，不要求前置法则。“极寒脆性”让快速冷热转换本身可以造成法则伤害。热质量系数扩至 0.12–8 倍，极寒滑行阻力降至 5%，温暖高速物体每米磨损 10% 质量；汽化反冲、引力、放电和爆炸的作用也已增强。物体磨损到初始质量的 10% 以下会消失；已解锁爆炸且动能足够时，改为爆炸。热胀冷缩已经实现，边界墙本身保持固定尺寸。

## Inspector 与复现

- ArenaDirector：场景、Prefabs、WorldGenerator 与 WorldTuning 引用。Random Seed 为 0 时每局生成新种子；非零值可以复现布局和三选一法则池。
- Assets/ArenaDemo/WorldTuning.asset：成长、怪物数量、固定河流、世界边距、温度和速度上限、新法则阈值等参数。Player Health Growth / Enemy Health Growth 控制生命成长；Staff Damage 为固定普攻伤害；River Center Y / River Width 控制常驻河流。
- WorldGenerator：小石头、大石头、树木和地形材质引用；每周目保留宽通路，检查出生点、世界钟、守卫和碎片的可达性。
- Assets/ArenaDemo/Prefabs：实体与魔法组件，可直接在 Inspector 调整。
- Tools / Phase Arena / Upgrade World Laws Demo：更新现有演示场景和引用。
- Tools / Phase Arena / Bake World UI Font：重新烘焙 Demo 的中文字符；不改项目的全局字体。

场景包含可检查的预览地图。运行时会根据当前局与周目种子重新生成地图。新增界面沿用 uGUI 和 TMP；自用 ArenaFont 是静态字符集。

## 验证文件

本次验收写入 Verification/world-mechanics.json、Verification/world-combinations.json 和 Verification/world-full-run-种子.json。旧 mechanics.json 与 full-run.json 属于此前的波次版。

最新反馈的短程验收写入 Verification/feedback-mechanics.json，包含新法则的真实物理效果、固定河流与布局、生命成长和随机卡牌状态夹具。此前 104 项检查及完整实战记录属于上一版，不能冒充本版自然通关验收；整局难度与时长交由手动试玩，结果见 Verification/ACCEPTANCE.md。

分项验收使用明确标识的物理夹具和状态夹具；完整运行仅通过正式的移动、施法、法杖、碎片拾取和可点击 UI 完成，不修改生命、不强制删除敌人、不传送玩家。完整验收采用加速模拟，报告的 elapsed 是游戏内时间，simulationSpeed 记录加速倍率；实际游玩默认一倍速。验收组件仅在 Editor 编译，不保存到场景。

Verification/before-world-law-rework.zip 保存本次改造前的场景、脚本、Prefabs、物理设置和说明，供恢复。

Verification/before-growth-river-new-laws.zip 保存本轮成长、地图和四条新增法则改造之前的版本。

远程怪物：19 个游荡怪物中的 3 个替换为紫色投掷怪，保持怪物总数不变。它们会保持约 5 单位距离，显示攻击方向和前摇后，交替投掷冰火实体；投射物调用与玩家相同的生成和碰撞逻辑，可被 F 反击。

法力：玩家蓝条上限 200，冰火每次蓄力完成消耗 10，战斗与探索期间每秒回复 5；法力不足不产生投射物、不进入冷却。F 与护盾不消耗法力；新开局和进入新周目回满，暂停、选择法则和死亡期间不回复。

撞击升温：温度换算强度提高到原来的 8 倍，动能损耗比例仍为 45%，单次每个物体升温最多 400°C。玩家投射物从实际碰撞体中心计算出生位置，路径上有障碍物时缩短距离。新生成的投射物仍可立即被 F 击飞，贴近障碍物时偶尔踢中属于玩法。

玩家美术：使用 Assets/ArtSources/MagicCharacter 中的四向蓝袍法师，使用新增的四向行走图集，每个方向 4 帧，移动时按每秒 8 帧循环，停止时保持朝向并使用该方向首帧；隐藏旧占位法杖渲染，碰撞体与施法方向逻辑保留。

投射物新操作：玩家按住左键或右键蓄力 0.3 秒，期间可以移动，只有跟随瞄准的预览动画。提前松开取消且不扣法力；蓄满后松开鼠标才创建静止实体，或者按 F 创建并踢出，创建成功时扣一次法力。每次按住只生成一球，松开后可再次蓄力。出生位置从实际碰撞体中心计算，使用真实世界尺寸，球与玩家表面通常间隔 0.18 单位；路径有障碍时缩短距离，但至少保留 0.06 单位间隔。空间不足时不生成、不扣法力。恢复碰撞检查真实碰撞体间距，自己的球返回时仍能伤害玩家。玩家球没有初始冲量，成球后用 F 踢出，也可以留在地上；敌方仍会投掷。双方投射物共用 250 个场地上限，超过时移除最早生成的一个，没有定时寿命；碰撞损毁、法则爆炸和切换周目仍会移除。

树木碰撞：BurnableTree 保留胶囊碰撞体，ThermoBody 负责温度、血量和碰撞行为，生成器引用该组件。生成与热胀冷缩支持胶囊尺寸及偏移，不要求树使用圆形碰撞体。

法则统一检查：石头、玩家/敌方基础投射物、普通怪物、Boss 和玩家共用温度、质量、摩擦、弹性、冲量和碰撞反应。摩擦磨损要求速度大于 5 且温度高于常温；冷球仍会摩擦升温，冰面不摩擦生热。悬停所有实体均可查看物质剩余比例。引力系数从 24 调到 30，且热更新的力按整个更新时间换算成冲量，修复每 0.1 秒只作用一个物理帧的衰减。条件仍为冷重源质量至少 4、温度低于 -50，吸引质量小于 2、温度高于 40 的动态实体，范围 8。
